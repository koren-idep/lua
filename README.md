# Lua / LuaJIT / Luau (`org.koren.lua`)

Lua, LuaJIT, and Luau language support via LuaLS, luau-lsp, and Lune.

- **Supported extensions:** `.lua`, `.lj`, `.luau`
- **Declared optional tools (via Tool Manager):** `lua-language-server`, `luau-lsp`, `lua`, `luajit`, `lune`

> External tools are not bundled with this extension; Koren's Tool Manager registers them so you can detect, configure, or install them on demand.
